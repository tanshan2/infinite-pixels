# 知衡 · 家庭财务与美元债分析（前端演示版）

服务准备移居香港及已在香港生活的内地家庭：用户提出实际问题 → 平台调用确定性计算 → 给出能核对的答案 → 按需请真人复核。

> 原 Demo 网址（zhiheng-finance-lab-1020…chatgpt.site）在构建时无法解析，仓库中也没有其源码，因此本项目从零实现，技术栈为 React + TypeScript + Vite。

## 启动

```bash
cd zhiheng
npm install
npm run dev        # 开发：http://localhost:5173
npm test           # 金融计算与问题分流单元测试（vitest）
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览构建产物
```

使用 Hash 路由，`dist/` 可作为纯静态文件部署在任意子路径。

## 信息架构

| 路由 | 页面 | 作用 |
|---|---|---|
| `#/` | 个人工作台 | 问题输入框、示例问题、四个工具入口、我的概览（示例／未连接状态标注） |
| `#/plan` | 香港落地资金规划 | 参数表单 + 统一结果页；收支缺口、备用金、各币种需求、兑换安排、未分配资金 |
| `#/bonds` · `#/bonds/:id` | 美元债研究与测算 | 列表；详情含条款、四种收益率、现金流、久期、利率／利差压力测算、债务顺位、主权／企业分析要点、来源入口 |
| `#/analysis` | 分析结果 | 统一六步：一句话回答 → 关键数字与图表 → 影响因素 → 来源／公式／假设 → 缺失与局限 → 下一步 |
| `#/news` | 信息与新闻中心 | 四个分类；事实与平台解读分开；传导路径；官方来源导航 |
| `#/experts` | 真人一对一 | 四个领域分流、当地许可与核查入口、七步流程、咨询准备单、登记意向、咨询记录 |

## 视觉方向

深墨绿（`#173b33`）为结构色，暖白纸面，石灰色分隔线；金色只用于一句话回答的引导线与少量强调，青绿用于链接和“条件测算”标签。标题用宋体系衬线字，正文用无衬线字，数字统一使用等宽数字。用分隔线和留白组织信息，避免满屏卡片。陈述类型（事实／条件测算／估计／观点）和数据状态（示例／未接入等）都用“文字 + 形状”表示，不只依赖颜色。图表配色经色觉差异校验脚本检查，每张图都标出单位、币种、口径和图例，并附数据表。

## 金融计算与适用范围

- 债券：30/360 日计数；按票息频率复利；结算日按价格日 T+2（只跳过周末）推算；二分法求收益率（结果可复现）；当期收益率、YTM、各赎回日 YTC、YTW；Macaulay／修正久期、凸性、DV01；利率 + 利差平行冲击的全价重估，并附久期凸性近似用于核对。
- **未支持**（明确标注、不输出数字）：永续／重置票息（如 AT1）、浮息、摊还、含权债的 OAS、违约回收。
- 落地资金：月支出、无收入过渡期、持续缺口、备用金（按全部支出计）、各币种需求匹配（先动用美元、再港元、最后人民币）、人民币兑换汇率缓冲、个人年度购汇便利化额度提示、未分配资金（明确不等于可投资金额）。

测试覆盖（29 项）：30/360 月末规则、T+2、平价债 = 100、教科书算例（10 年 6% 半年付、收益率 8% → 86.4097）、应计利息、定价与求解互为逆运算、零息债久期 = 期限、5 年 5% 平价债久期 4.5460、久期／凸性与有限差分一致、YTW 取最小、赎回日不在付息日时的不足一期计息、不支持的结构、压力测算对称性与凸性、规划各分项与币种匹配、输入校验、问题分流。

## 功能状态

**已实现（可用）**
- 落地资金规划：输入校验、重新计算、恢复示例、公式与假设展示
- 债券测算：四种收益率、现金流、久期、自定义利率／利差情景、情景矩阵、假设价格
- 统一结果页：通俗／专业切换、陈述类型标注、“资料不足，暂不能判断”
- 问题分流（关键词规则）与三个计算模板
- 咨询准备单：生成、下载 .txt、打印；资料共享默认不勾选
- 无障碍：跳转链接、表单标签与错误提示关联、焦点样式、路由切换焦点管理、图表数据表

**演示（明确标注）**
- 4 只虚构债券（价格为示例，非报价；ISIN 为演示代码）
- 3 条围绕虚构发行人的新闻；香港政策与利率宏观类只有官方来源导航
- 汇率与示例家庭参数

**仍需接入的服务**（契约见 `docs/API.md`，前端只调用同源 `/api`，密钥只放后端）
- 债券参考数据与价格（区分延迟参考价与可成交报价）
- 新闻与公告抓取（保留原文链接、发布时间、获取时间）
- AI 解读：只负责理解问题与组织解释，关键数字仍由本地计算模块产生
- 专家入驻、排期、费用确认、预约与咨询记录
- 账户连接（持仓导入）

## 隐私

财务输入只保存在 React 内存状态中，刷新即清除；不写 localStorage／sessionStorage，不发送给第三方。`VITE_API_ENABLED` 未设为 `true` 时前端不发出任何网络请求。用户输入一律以文本渲染，不使用 `dangerouslySetInnerHTML`。
