# 知衡后端 V1

Node.js 22.16+。沿用同源 `/api`，没有前端密钥。四个接口与 `API.md` 保持兼容。

## 本地运行

```sh
npm install
cp .env.server.example .env.server
npm run build:server
npm run start:server
```

另一终端：

```sh
VITE_API_ENABLED=true ZHIHENG_API_TARGET=http://127.0.0.1:8787 npm run dev
```

`APP_ORIGIN` 应与浏览器前端来源一致；Vite 如更换端口也需要同步。生产反向代理 `/api` 到后端，并设置 `APP_ORIGIN=https://正式前端域名`。本实现不更改现有公开 Demo，不自动部署。

验证：`npm test`、`npm run build`、`npm run build:server`。`GET /api/health` 仅报告连接配置状态，不保证上游可用。

## 数据行为

- 新闻：从固定的香港政府 RSS 地址读取标题、链接和发布时间，五分钟缓存，首次或过期请求触发更新，并合并并发请求。状态为 delayed，不声称秒级实时。失败时旧缓存为 stale，无缓存为 missing。不用示例新闻补位，不生成未经证实的新闻解读。目前未覆盖评级、债券发行人或全球新闻。
- 债券：未配置时 unconnected；显式 `BOND_SAMPLE_MODE=true` 才提供前端同一份虚构数据。授权上游配置后只接受规范化 `{source,asOf,data:BondRecord[]}`，字段结构见前端类型；价格时间和 asOf 为带时区 ISO 时间。仅接受 indicative 参考价，拒绝 sample/executable，超过一天标 stale。不内置数据商账户或假设第三方原生字段可直接使用；商用分发权需与数据商确认。
- 分析：配置服务端 `ANTHROPIC_API_KEY` 和明确的 `ANTHROPIC_MODEL` 后调用 Messages API；未配置返回 503。仅返回 `{summary}`。系统指令禁止报价、评级、预测或生成计算数字，并拦截含阿拉伯数字/百分号的输出；此校验不构成金融事实正确性的保证。没有模型密钥时不伪装为 AI。用户问题会发送给 Anthropic，提交前须告知用户勿写账户、证件及其他敏感信息。
- 隐私：当前 contract 无单独的外部共享同意字段，故拒绝所有 `context`，不把财务参数发送给模型。服务不记录正文，不持久化 AI 对话。
- 咨询：只有配置 `CONSULT_INTENT_DIR` 才接受登记。每次生成不可预测编号，以独立 JSON 文件保存，文件权限 0600，新目录 0700，写入成功才返回 201。不提供公开读取接口，不发送邮件、不联系专家、不产生预约。保存 shareItems 授权范围，实际附带资料为空；当前前端只传范围，不传具体规划内容。

## 专业计算

继续只使用 `src/lib/finance/bond.ts` 与 `planning.ts`，未复制公式。后端本轮不增加财务计算接口；29 项已有测试保持在同一测试命令中执行。

## 上线前必须完成的运营配置

当前为可联调的单实例后端。咨询数据需持久化私有磁盘及访问控制、明确保留期限和删除流程；不应存入静态站点目录或 Git。多实例应替换为数据库并使用共享缓存／限流。按 IP 的内存限流仅限单实例，默认不信任 X-Forwarded-For，反向代理后应由网关限流。接入账号鉴权、反机器人控制和显式的个人资料处理声明后再公开收集真实联系方式。当前没有运营后台或已入驻专家。

不要对没有取得授权的数据商、AI 或个人资料服务直接启用生产流量。

## 免费公开数据模式（默认方向）
不需要采购数据商服务。新增 GET /api/public-bonds 返回人工核对的真实美元债基本事实，价格始终 null；每项有官方来源与核对日期。香港政府四只美元债和菲律宾两只主权美元债为首批目录，非完整市场覆盖。目录不会自动宣称信用状态／条款最新。
GET /api/treasury-curve 读取美国财政部每日票面收益率曲线 XML，一小时请求缓存，超过五个自然日的数据为 stale；上游失败不换成示例数值。这是 par curve，不是单只债券行情或零息折现曲线。
债券页默认展示真实公开目录。用户填写净价和结算日、选择付息频率并确认模型假设后，复用原有 bond.ts 计算条件收益率和压力情景。不完整日期禁止计算；未确认特殊条款时不提供 YTW。虚构样本另列教学标签页，不混入真实目录。
公开事实仅摘录必要字段，原文以官方链接提供，不整篇复制报告。来源许可或条款变化时应重新检查。当前没有自动发行文件解析或全球实时信用事件覆盖。

验证记录（2026-10-20）：41项测试通过，类型检查及前后端构建通过；政府 RSS 已实际读取。美国财政部官方 XML 在当前执行网络超时，解析器由结构化样本测试覆盖，尚未完成该源的端到端验证；运行失败时为 missing，不承诺当前可用。
