# 高密度体素地球渲染器设计

## 目标

把主页当前可见地球替换为参考图所示的高密度体素地球，同时完整保留已经确认的传送门前景、页面布局、中文界面和交互状态机。地球默认位于传送门后方；访客双击或双触地球后，才进入可旋转、缩放和选择地点的激活状态。

## 已确认的视觉方向

- 采用实时 Canvas 球面体素渲染，不把参考图直接作为页面图片，也不引入 WebGL。
- 地球由经纬网格单元构成。桌面端约为 88 × 44 格，手机端约为 64 × 32 格；在保持清晰像素感的同时控制移动设备绘制开销。
- 海洋使用深青绿色体素表面；陆地使用橄榄绿至金黄色体素，并相对海面抬高约一个视觉体素高度。
- 海岸线保持阶梯状，不进行平滑描边。陆地边缘显示较暗侧面，使大陆具有明确厚度。
- 光源来自左上方：左上表面偏暖、偏亮，右下逐渐变暗；球体边缘进一步压暗，形成参考图中的立体轮廓。
- 每个可见单元具有细暗边框、顶部微亮边和较暗下沿，但不加入与参考图无关的发光、粒子或装饰。
- 地点标记投影到抬高后的陆地表面，随地球旋转、缩放并保持命中区域对齐。

## 保留内容

- 传送门图片、牌匾、前景层级和当前 0.85 缩放保持不变，且始终覆盖在地球前面。
- 保留双击唤醒、触屏双触唤醒、拖拽旋转、滚轮或双指缩放、自动旋转、停止操作两秒后继续旋转、地点选择、键盘操作、语言切换和减少动态效果支持。
- 中文为默认界面。除 UI、AI 等专业词汇外，不新增普通英文文案。
- 不改变作品入口和地点入口之间已经确定的信息架构。

## 渲染架构

### 数据层

现有 `data/world.geojson` 继续作为大陆边界的唯一数据来源。GeoJSON 先被栅格化为轻量陆地遮罩，再按当前设备密度生成球面单元列表。每个单元记录经纬度范围、中心向量、四个角点、陆海类型、相邻陆海状态和稳定的微小色差。

单元只在以下情况重新生成：

- GeoJSON 首次加载完成；
- 视口跨过桌面与手机密度断点；
- 渲染所依赖的数据恢复或重新加载。

旋转动画本身只更新投影和绘制，不重复进行 GeoJSON 解析或陆地分类。

### 几何层

每一帧先把预计算的球面向量应用当前偏航角和俯仰角，再执行正交投影。可见半球的单元按深度从远到近绘制：

1. 海洋顶面位于基础球半径；
2. 陆地顶面位于略大的半径；
3. 陆海交界边绘制从陆地顶面连接至海面的侧面；
4. 最后绘制地点标记和交互高亮。

极区的经线自然收敛，单元会变窄；不强行拉伸为等宽方块，以免旋转时出现裂缝或地图失真。背向观察者的单元不绘制。

### 材质与光照

颜色由陆海基础色、固定左上光源的漫反射、球面边缘衰减、单元稳定色差和交互高亮共同决定。单元色差由经纬格索引计算，不使用每帧随机数，因此旋转时不会闪烁。

侧面颜色始终比对应顶面更暗。边框和亮边的透明度会随屏幕密度调节，避免手机端缩小时出现黑块。

### 与现有交互的连接

现有 UI 状态机继续管理未激活、激活、拖拽、缩放、自动旋转和减少动态效果。渲染器只读取当前角度、缩放和选择状态，不改变这些交互规则。

地点坐标与单元共用同一套球面旋转及投影函数。陆地点使用抬高半径，保证标记不会陷入大陆表面。命中测试仍在 Canvas 坐标中完成。

## 响应式与性能

- 桌面端使用约 88 × 44 单元；窄屏使用约 64 × 32 单元。
- Canvas 内部像素尺寸高于当前 160 × 160，以容纳体素边框和侧面细节；CSS 显示尺寸及页面占位保持不变。
- 自动旋转沿用当前受控帧率；静止且没有闪烁标记时不持续重绘。
- 渲染器缓存单元几何和陆海分类，帧内不创建大型图像缓冲区。
- 若设备性能较弱，优先降低单元密度，不改变交互功能和传送门层级。

## 失败处理

- GeoJSON 加载失败时显示现有中文错误状态，不呈现伪造大陆。
- Canvas 不可用或渲染发生异常时，传送门入口、可访问状态文字和导航仍可使用。
- 参考图只用于视觉对照，不作为生产资源，因此不会把白灰棋盘背景或参考图中的任何文字带入网站。

## 测试与验收

### 自动化测试

- 密度选择：桌面为高密度，手机为较低密度。
- 球面几何：陆地半径高于海洋，背面单元被剔除，深度排序稳定。
- 颜色系统：海洋保持深青绿，陆地保持橄榄至金黄，侧面比顶面暗。
- 投影一致性：地点标记与球体使用相同角度、缩放和陆地高度。
- 回归测试：现有双击、触屏、拖拽、缩放、自动旋转、语言和传送门测试继续通过。

### 浏览器与视觉验收

- 桌面与手机截图分别对照两张参考图，重点检查体素密度、陆地高度、海陆颜色、左上光照、球面轮廓和阶梯状海岸。
- 验证传送门始终在地球前方，地球未激活时不旋转，激活后旋转与缩放正常。
- 验证中文初始界面没有新增普通英文。
- 验证窄屏没有横向滚动，地点按钮没有脱离对应大陆。

## 非目标

- 本次不重做传送门、页面导航、作品子页面或地点子页面。
- 本次不增加新的地点、作品或文字内容。
- 本次不把地球迁移到 Three.js/WebGL，也不直接裁切或抠取参考图作为成品资产。
