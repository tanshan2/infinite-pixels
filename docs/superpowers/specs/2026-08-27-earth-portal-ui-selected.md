# 地球与传送门 UI 定稿

## 当前范围

本阶段只落实主页第一屏的地球与传送门 UI。漂浮游戏岛、创作者公寓、独立游戏工作室以及三个地点子页面继续保留为后续设计工作，本阶段不制作。

选定视觉稿：`design-references/earth-portal-ui-v3.png`。

## 选定方向

- 采用第三版：页面不显示“无限像素”或“Infinite Pixels”文字标识。
- 品牌改为无文字像素徽记，融入传送门两侧和门柱上的暗红旗帜，成为场景纹章，而不是悬浮在页面角落的 UI 标识。
- 右上角只保留语言切换；中文模式显示“中文 · 英文”。
- 地球位于后景，传送门庭院位于前景并遮挡地球下缘。
- 传送门保持参考图的暖色石门、暗红牌匾、金色灯光、旗帜、树木、花坛、半圆平台和中央小角色。
- 中文牌匾只显示“全部作品”。

## 地球状态

### 休眠状态

- 首次进入时地球静止，地点标记可见但不可点击。
- 拖动、滚轮、缩放按钮和地点选择均不响应。
- 桌面提示显示“鼠标双击地球唤醒”；触摸设备显示“双击地球唤醒”。
- 第三版按需控件保持隐藏。

### 激活状态

- 鼠标双击、触摸双击、键盘 Enter 或 Space 激活地球。
- 激活后地球平滑放大，并开始低速自动转动。
- 用户拖动时自动转动暂停，松手两秒后恢复。
- 激活后开放拖动旋转、滚轮缩放、双指缩放和地点选择。
- 缩小、重置、放大控件只在用户移入地球、触摸地球或键盘聚焦时显示。
- 地球在任何缩放状态下都不能越过传送门前景，也不能出现方形 Canvas 裁切。
- 当前访问期间保持激活；刷新或关闭页面后恢复休眠。

## 传送门状态

- 传送门从页面加载开始就可聚焦、悬停和点击，不依赖地球是否激活。
- 悬停或聚焦时只增强门洞的暖光和牌匾边缘，不使用霓虹或粒子。
- 点击后播放约 450 毫秒的暖光增强与全屏淡出。
- 本阶段尚未设计作品子页面，因此不创建或猜测目标页面；过渡结束后恢复主页并通过状态文字说明“作品空间正在设计中”。后续子页面设计通过后再接入真实导航。
- 开启“减少动态效果”时跳过放大、自动转动、淡入和传送过渡，但保留状态切换及所有操作能力。

## 中文规则

- 中文模式所有可见文字使用中文，不出现普通英文。
- UI、AI 等公认专业词汇可以保留，但本主页不需要显示这些词。
- 中文地点名为“广州”“印第安纳波利斯”“多伦多”。
- 中文模式隐藏现有 `PIXEL SOURCE 128×64` 等技术说明。
- 英文模式才显示英文地点名和英文操作提示。

## 视觉资产

- 现有地球继续使用 `data/world.geojson` 和 Canvas 逐像素渲染。
- 新增一张透明背景的体素传送门庭院前景图片，构图、材质和光照以选定视觉稿为准。
- 图片中的牌匾保留空白暗红底，使用页面文字覆盖“全部作品”，以保证中英文切换和文字准确性。
- 无文字像素徽记直接绘制在生成资产的旗帜上，不额外创建角落标识。
- 小角色属于传送门庭院前景资产，本阶段不赋予移动能力。

## 响应式与无障碍

- 桌面维持 16:9 舞台式构图；地球居中偏上，传送门平台横跨下方。
- 窄屏优先保持门、地球和中央角色可见，可裁减两侧花园，但不能遮挡牌匾、语言按钮或激活提示。
- 传送门使用真实按钮或链接语义；地球舞台可聚焦，并提供清晰的 `aria-label`。
- 双击不是唯一激活方式，键盘 Enter 和 Space 必须等效。
- 触摸目标不小于 44×44 CSS 像素。
- 状态变化通过 `aria-live` 说明，不只依赖颜色。

## 验收标准

1. 首屏构图与选定第三版视觉稿一致，且不显示“无限像素”文字标识。
2. 无文字徽记只出现在传送门旗帜上。
3. 地球默认休眠，双击或键盘激活后放大并缓慢转动。
4. 拖动时暂停自动转动，松手两秒后恢复。
5. 地点标记休眠时可见但不可操作，激活后恢复现有地点互动。
6. 按需控件只在激活后的移入、触摸或键盘聚焦状态显示。
7. 传送门始终位于地球前方，所有地球交互不会破坏该层级。
8. 中文模式只显示中文界面文字，并移除技术英文说明。
9. 桌面、窄屏、触摸、键盘和减少动态效果状态均可用。
10. 参考图、选定视觉稿和浏览器实现以同一视口并排检查，P0、P1、P2 问题全部修复。

## 非目标

- 不制作作品子页面、漂浮游戏岛、公寓、工作室或地点子页面。
- 不实现角色移动、场景探索、作品卡片、筛选或内容后台。
- 不发布线上版本；本阶段只完成本地实现和视觉验收。
