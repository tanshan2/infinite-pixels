# 无限像素传送门主页与作品页设计规格

## 目标

在现有可交互 3D 像素地球主页上加入参考图中的体素传送门前景，并建立可进入的作品子页面。传送门是默认主操作；地球默认休眠，只有用户双击后才激活。地球在所有状态下都保持在传送门后方。

本次采用此前 UI 布局对比中的第三版：操作控件默认隐藏，只在地球激活且用户移入、触摸交互或键盘聚焦时按需显示。

## 视觉基准

- 以用户提供的体素场景参考图为视觉基准，不重新发明传送门风格。
- 保留深青黑背景、暖色石材、暗红牌匾、金色文字、灯笼、旗帜、树木、花坛和半圆平台。
- 传送门前景使用与参考图一致的体素像素质感，并作为独立真实图片资产放置；不使用 CSS 拼画、内联 SVG、表情符号或占位框模拟。
- 现有真实 GeoJSON 像素地球、深青海洋、绿色陆地、自然光照和三处地点标记继续使用。
- 传送门必须在视觉层级上遮挡地球下部；地球放大、旋转或地点交互时都不能越过传送门前景。

## 主页层级与布局

从后到前的固定层级为：

1. 深青黑全屏背景。
2. 现有 Canvas 像素地球及地点标记。
3. 激活提示、语言切换和按需地球控件。
4. 体素庭院平台与传送门前景。
5. 传送门可点击区域、键盘焦点和页面过渡层。

桌面端地球保持视觉中心偏上，传送门位于下方中央并覆盖地球下缘。窄屏下按比例缩小传送门和地球，仍保持传送门在前、地球在后，不产生横向滚动。

牌匾在中文模式只显示“全部作品”，英文模式显示“ALL WORKS”。传送门整体和门洞都属于同一个点击目标。

## 地球状态

### 休眠

- 页面首次进入时地球保持静止，拖动、滚轮、单指移动和地点点击均不响应。
- 广州、多伦多和印第安纳波利斯标记保持可见，但处于非互动状态。
- 中文桌面提示显示“鼠标双击地球唤醒”；中文触摸设备显示“双击地球唤醒”。
- 休眠状态不显示缩放和重置控件。

### 激活

- 桌面鼠标双击、触摸设备双击、键盘 Enter 或 Space 均可激活地球。
- 激活时地球平滑放大到安全范围内，并开始缓慢自动转动。
- 激活在同一次访问中持续有效，不通过再次双击关闭；关闭页面后恢复休眠。
- 用户拖动地球时自动转动立即暂停；松手约两秒后恢复缓慢转动。
- 激活后开放拖动旋转、滚轮缩放、双指缩放、地点选择和重置视角。
- 激活提示替换为“拖动旋转 · 滚动缩放”；英文模式显示完整英文译文。

### 第三版按需控件

- 地球激活后，鼠标移入地球、触摸地球或键盘聚焦控制区域时显示缩小、重置和放大控件。
- 鼠标离开且没有键盘焦点时，控件延时淡出，避免突然闪烁。
- 控件不覆盖传送门牌匾或门洞点击区域。
- “减少动态效果”开启时取消自动转动和淡入动画，但保留所有操作能力。

## 传送门导航

- 传送门是主页默认可用的主要入口，不依赖地球是否激活。
- 鼠标点击、触摸点击、键盘 Enter 或 Space 均进入作品页。
- 进入前播放约 450 毫秒的暖光增强与全屏淡出，再导航到作品页。
- 系统要求减少动态效果时直接导航，不播放过渡。
- 传送门点击不会误触地球拖动或双击激活。

## 跨页面状态

- 在同一次浏览访问中保存地球激活状态、朝向、俯仰和缩放。
- 从作品页返回主页时恢复离开前的地球视图，并继续保持激活。
- 当前语言在主页和作品页之间保持一致。
- 状态只保存在当前浏览会话，不建立账号、数据库或长期用户档案。

## 语言规则

- 中文模式的所有可见导航、提示、地点名、按钮和状态信息均使用中文。
- 中文模式不出现普通英文文案；UI、AI 等公认专业词汇允许保留。
- 中文语言切换显示“中文 · 英文”；英文模式显示“中文 · EN”。
- 品牌在中文模式显示“无限像素”，英文模式显示“Infinite Pixels”。
- 页面标题、无障碍标签、错误信息和作品页空状态都随语言同步切换。

## 作品子页面

- 新增独立作品页和明确的返回主页入口。
- 视觉延续传送门内部的暗红、石材、暖灯和深青背景，但减少大型场景装饰，为未来作品内容保留空间。
- 页面标题在中文模式显示“全部作品”，英文模式显示“ALL WORKS”。
- 当前没有真实作品资料时显示诚实的“作品正在整理中”空状态，不编造项目、封面、客户或发布日期。
- 页面结构为未来作品卡片预留稳定容器，但本轮不添加虚构卡片、筛选器或详情页。
- 返回主页后恢复本次访问中的语言和地球状态。

## 无障碍与输入

- 地球休眠区、传送门和隐藏控件都提供可读的 `aria-label` 和键盘焦点样式。
- 双击不是唯一激活方式；键盘 Enter 和 Space 可完成相同操作。
- 触摸目标不小于 44×44 CSS 像素。
- 休眠与激活状态除了颜色变化，还通过提示文字和 `aria-live` 状态说明区传达。
- 地点标记休眠时设置为不可操作，激活后才进入键盘顺序。

## 错误与降级

- 传送门资产加载失败时，保留可点击的普通“全部作品”入口，不能阻止访问作品页。
- GeoJSON 或 Canvas 渲染失败时，传送门仍然可用，并显示对应语言的地球加载错误。
- 会话状态读取失败时使用默认休眠视图，不抛出未捕获错误。
- JavaScript 被禁用时提供普通链接进入作品页和返回主页。

## 验收标准

1. 初次打开主页时地球静止，地点标记可见但不可交互，传送门立即可点击。
2. 传送门视觉保持参考图的体素石门、红色牌匾、暖灯、旗帜、树木、花坛和平台设计。
3. 双击或键盘激活地球后，地球安全放大并缓慢转动；拖动时暂停，松手约两秒后恢复。
4. 地球在所有旋转和缩放状态下都保持在传送门后方，且不出现方形 Canvas 裁切。
5. 第三版控件只在激活后的移入、触摸或键盘聚焦状态显示。
6. 点击传送门经过约 450 毫秒过渡进入作品页；减少动态效果时直接进入。
7. 作品页没有虚构内容，能返回主页并恢复语言、激活状态、朝向和缩放。
8. 中文模式除 UI、AI 等专业词汇外不出现普通英文；中文语言按钮显示“中文 · 英文”。
9. 桌面、窄屏、触摸和键盘操作均可用，页面无横向滚动和控制台错误。
10. 参考图与最终主页在相同视口、相同休眠状态下完成并排视觉检查，P0、P1、P2 问题全部修复。

## 非目标

- 本轮不制作真实作品卡片、作品详情页、搜索、筛选、登录、后台或数据库。
- 本轮不把传送门改造成实时 3D 模型，不添加霓虹、粒子、星空或科幻 HUD。
- 本轮不新增城市子页面，也不改变现有三处地点数据。
- 本轮不发布线上版本；先完成本地视觉和交互验收。
