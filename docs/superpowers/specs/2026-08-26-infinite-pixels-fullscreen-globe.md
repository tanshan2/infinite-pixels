# Infinite Pixels 全屏像素地球视觉规格

## 状态

- 状态：已获用户确认（A）
- 日期：2026-08-26
- 适用页面：主页 `index.html`
- 参考：用户提供的全屏像素地球截图

## 目标

将主页收敛为一个全屏、低干扰的 3D 像素地球界面。初始视图只显示截图中可见的界面元素，同时继续保留真实 GeoJSON 地形、三个地点标记和既有地球交互。

## 可见构成

1. 深色纯色全屏背景。
2. 视口正中央的 3D 像素地球；地球随视口缩放，保持像素边缘，不出现卡片边框或标题区。
3. 右上角中英文切换按钮，文案保持“中文 · EN”。
4. 地球下方的三个控制按钮：`−`、`重置`、`＋`。
5. 底部操作提示：`拖动旋转 · 滚轮缩放 · 双指缩放` 与 `PIXEL SOURCE 128×64`。

## 明确移除

- 页面标题、眉题、双语介绍段落。
- 地球标题、副标题、版本说明、页脚。
- 地球外层卡片的边框、圆角、内边距和额外装饰。
- 初始视图中任何额外的可见导航或说明。

SEO 元数据（`title`、`description`、canonical、Open Graph、JSON-LD）保留在 `<head>`，因为它们不属于可见 UI，且主页仍需被 Google 正常索引。

## 位置与响应式约束

- 根页面使用 `100dvh` / `100vw`，禁止页面滚动，背景延伸到整个视口。
- 桌面视口中地球水平、垂直居中；尺寸目标为 `min(60vw, 64vh, 560px)`。
- 控件和提示与地球中心对齐，位于地球下方并贴近视口底部。
- 窄屏（约 `760px` 以下）时，地球继续水平、垂直居中，宽度目标为 `min(88vw, 64vh, 560px)`，控件和提示同步居中。
- 语言按钮固定在右上角，距离视口上/右边缘约 8–10px。

## 交互与状态

- 鼠标拖动旋转、滚轮缩放、双指缩放；不自动旋转、不使用惯性。
- `−` / `＋` / `重置` 行为保持现有实现。
- 缩放必须有统一的安全上限：地球半径始终小于内部像素画布半径，并保留可见像素边距；到达上限后继续滚轮、按钮或双指操作不再放大。
- 缩放上限采用约 `1.1×` 的固定安全值，避免放大地球覆盖整个屏幕，也避免固定方形画布裁切出方框。
- 广州、印第安纳波利斯、多伦多标记继续使用真实坐标和现有 GeoJSON 投影。
- 地点名牌按用户选择 A：默认隐藏；点击可见标记后显示对应城市名称，拖动或点击空白后按现有逻辑清除。
- 语言切换继续更新按钮、提示、加载和地点名牌文案，不新增可见面板。

## 无障碍与索引

- 保留一个视觉隐藏的 `h1` 作为文档主标题，保证语义与 SEO，不改变截图中的可见画面。
- 保留按钮的 `aria-label`、地点选择导航和地球 canvas 的可访问标签。
- 无 JavaScript 提示保持视觉隐藏，仅作为无障碍/降级内容。

## 验收标准

- 浏览器截图中除居中的地球、语言按钮、三个控制按钮和底部提示外没有其他可见内容。
- `document.documentElement.scrollHeight === window.innerHeight`（允许浏览器 1px 舍入误差），页面不出现滚动条。
- 地球绘制区域的中心与视口中心误差不超过 1px；控件和提示中心与地球中心一致。
- 在默认、最小和最大缩放状态下，Canvas 的非透明像素不接触四条边，地球保持完整圆形，不出现方形裁切区域。
- 真实地图数据仍成功加载，三个地点标记可点击，城市名牌默认隐藏且点击后显示。
- 拖动、滚轮缩放、按钮缩放和重置均可用；开发日志无错误。
- 本地预览和 GitHub Pages 发布页面均通过相同检查。
