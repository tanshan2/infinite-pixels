# 像素地球 3D 设计规格

## 目标

把已确认的真实陆地平面像素地图投影为一个可交互的 3D 像素地球，作为个人网站主页的地图视觉原型。当前阶段只制作地球模型，不加入地点标记、路线、国家标签或信息卡。

## 已确认的视觉方向

- 复用当前平面地图的真实陆地数据，2D 与 3D 使用同一份来源与坐标。
- 低分辨率像素纹理，使用最近邻采样；陆地边缘和球体轮廓都保留阶梯状硬像素。
- 自然光照：左上方柔和主光、深青色海洋、绿色陆地、轻微底部阴影。
- 深炭灰/深青色纯色背景，不使用星空、霓虹、光环或科幻 HUD。
- 球体居中展示，最大约 520px，随窗口响应式缩放。
- 初始朝向面向太平洋，方便后续连接亚洲与北美内容。
- 右上角保留“中文 · EN”；暂时不显示任何地图标点或文字标签。

## 交互

- 桌面：鼠标左键拖动旋转，滚轮缩放。
- 移动端：单指拖动旋转，双指缩放。
- 不自动旋转；松开后不产生惯性滑动。
- 缩放和旋转只影响球体视图，不改变地图数据。

## 数据与投影

- 平面底稿：等距圆柱投影的低分辨率像素地图。
- 3D 球面：将同一张平面纹理映射到球面，使用最近邻采样，禁止平滑插值。
- 陆地使用真实世界 GeoJSON 轮廓，确保非洲、南美洲及其他大陆保留。
- 纹理中的色块和像素棱角属于视觉处理，不重新手绘大陆形状。

## 非目标

- 本阶段不制作地点标记、国家标签、路线、个人经历卡片或子地图页面。
- 本阶段不加入复杂的 3D UI、星空背景、粒子、发光边缘或自动相机动画。

## 验收标准

1. 3D 球可自由旋转与缩放，桌面和移动端操作均可用。
2. 初始视角为太平洋方向，球体居中且最大尺寸约 520px。
3. 海陆颜色与平面底稿一致，纹理放大后可见方块像素，不出现柔和矢量描边。
4. 非洲、南美洲、北美洲、亚洲、欧洲和澳大利亚等主要陆地均可辨认。
5. 页面只显示球体和中文/EN 开关，不显示标点或地图标签。
