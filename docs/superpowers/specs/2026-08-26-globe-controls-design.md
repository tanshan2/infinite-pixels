# 3D 像素地球操作 UI 设计规格

## 目标

在现有 3D 像素地球模型上增加一个底部像素控制条，让用户可以用按钮完成缩放和视角重置，同时保留现有的鼠标、滚轮和触摸交互。

## 保持不变的内容

- 继续使用当前真实 GeoJSON 生成的 `128×64` 平面纹理并投影到球面。
- 保持当前逐像素球面渲染、自然光照、硬像素球体轮廓和太平洋初始朝向。
- 不加入地图标点、国家标签、路线、信息面板或新的大陆绘制逻辑。
- 右上角继续保留 `中文 · EN` 开关。

## 控制条布局

- 控制条位于球体正下方，水平居中。
- 三个按钮按 `−`、`重置`、`＋` 排列。
- 使用深青色按钮底、浅色 1px 像素边框、无圆角或仅 2px 圆角。
- 控制条不覆盖球面，不改变球体的响应式尺寸。
- 窄屏下保持水平排列；按钮最小触控尺寸为 `40×36px`，避免误触。

## 控件行为

- `−`：将当前缩放值减少 `0.1`，限制在 `0.78` 到 `1.55` 之间。
- `＋`：将当前缩放值增加 `0.1`，限制在 `0.78` 到 `1.55` 之间。
- `重置`：恢复 `yaw=Math.PI`、`pitch=-0.14`、`zoom=1`，重新渲染太平洋初始视角。
- 按钮操作不改变纹理或陆地数据，也不启动自动旋转或惯性。
- 按钮支持键盘聚焦和 Enter/Space 操作，并提供 `aria-label`。

## 与现有交互的关系

- 鼠标左键拖动仍然控制 `yaw/pitch`。
- 鼠标滚轮和移动端双指仍然控制 `zoom`。
- 单指拖动仍然旋转球体。
- 点击控制条时不触发画布拖动；控制条按钮和画布交互区域互不重叠。
- 语言开关只切换按钮与提示文字，不改变地图显示。

## 验收标准

1. 当前 3D 像素地球的大陆纹理、光照、像素轮廓和初始朝向与改动前一致。
2. 页面出现居中的底部 `− / 重置 / ＋` 控制条，且没有标点、标签或信息面板。
3. 点击 `−` 和 `＋` 可改变球体大小；点击 `重置` 可恢复默认朝向和大小。
4. 原有鼠标拖动、滚轮、单指和双指交互继续有效。
5. 控制按钮在桌面和移动端均可点击，键盘操作可用，控制台无错误。
