# 地球与传送门新版视觉接入设计

## 目标

把当前已确认的新版地球与传送门视觉接入主页：下方完整传送门庭院（含浮空平台）按 0.85 倍显示，并用新版体素地球替换现有 GeoJSON 像素地球视觉。

## 方案

- 从已确认的新版成品图提取一张透明背景的新版地球资产，保存为 `assets/earth-model-v2.png`。
- 在现有 `#globeStage` 中增加新版地球图片层；保留现有 Canvas 作为交互命中层和状态兼容层，避免破坏双击唤醒、地点按钮、缩放控件和语言切换。
- 将 `#portalGate` 及其现有透明前景图作为一个整体统一缩放到 0.85 倍；悬停、聚焦和进入动画使用同一缩放基准，不让动画恢复旧尺寸。
- 不改变地球位置、页面控件、地点文案、传送门牌匾语义和响应式断点；新版地球资产不携带文字，页面继续负责可访问文本和中英文切换。

## 验收标准

1. 主页加载后可见新版体素地球；旧的 GeoJSON 纹理不再作为可见地球模型。
2. 传送门庭院及其平台相对当前版本统一为 0.85 倍，保持居中和前景层级。
3. 中文初始文案、英文切换、传送门按钮、现有状态机测试继续通过。
4. 桌面和窄屏没有横向滚动，图片资源加载失败时页面仍保留可访问的传送门和地球状态。
